# 📱 UNIFAE Care - App de Acompanhamento Fisioterápico de Pacientes

## 🚀 Sobre o Projeto

O **UNIFAE Care** é uma aplicação mobile desenvolvida em React Native com Expo, que tem como objetivo proporcionar um acompanhamento fisioterapêutico mais próximo, eficiente e personalizado entre pacientes e fisioterapeutas.

A plataforma permite que os fisioterapeutas monitorem de forma contínua a evolução de seus pacientes, oferecendo planos de tratamento personalizados com base em suas necessidades específicas, além de coletar feedbacks relevantes sobre a execução dos exercícios. Em contrapartida, os pacientes têm acesso facilitado aos seus planos de exercícios, podendo registrar suas percepções, dificuldades e resultados, promovendo uma comunicação mais efetiva com os profissionais responsáveis

Dessa forma, o sistema busca fortalecer a relação entre paciente e fisioterapeuta, contribuindo para um acompanhamento mais preciso, humanizado e orientado por dados.

**Projeto desenvolvido no contexto da UCE VII – Parceria entre os cursos de Engenharia de Software e Fisioterapia do UNIFAE**

Desenvolvedores: Maria Luiza Nery Pinto, Vinícius Mendes Santos e Maria Eduarda de Oliveira Furini

## ▶️ Como rodar?

### 📦 1. Clonar o repositório
```bash
  git clone https://github.com/vinisantosfae/unifae_care.git
  cd unifae_care
```

### 📥 2. Instalar dependências
```bash
  npm install
```

### ▶️ 3. Rodar o projeto
```bash
  npm start
```
